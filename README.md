# Чтоб всё сошлось

Интерактивный спецпроект ко Дню экономиста. За раунд игрок принимает пять решений для города-государства, разбирает их последствия и учится обосновывать свой выбор.

## Запуск

Откройте `index.html` в браузере. Изображения, шрифты, стили и сценарии встроены в файл.

## Публичный сайт

Игра доступна [на GitHub Pages](https://d4v1d-cell.github.io/economist-day/) без авторизации. Публикация настроена на корень ветки `main`.

## Видеопоздравление

Добавьте файл `minister.mp4` в корень ветки `main`, рядом с `index.html`. После публикации плеер появится в игровом письме. До загрузки записи в письме доступно текстовое поздравление.

## Обновление

Замените `index.html` новой автономной сборкой. GitHub Pages автоматически опубликует изменения.
