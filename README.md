# Чтоб всё сошлось

Интерактивный спецпроект ко Дню экономиста: пять экономических решений для города-государства.

## Запуск

Откройте `index.html` в браузере. Изображения, шрифты, стили и сценарии встроены в файл; установка зависимостей и авторизация не нужны.

## Публичный сайт

GitHub Pages настроен на ветку `main`, корневую папку `/`.

Адрес: https://d4v1d-cell.github.io/economist-day/

## Обновление

Замените `index.html` новой автономной сборкой. GitHub Pages автоматически опубликует изменения.

## Проверки

Проверены экраны шириной 320, 390, 768, 844 и 1586 пикселей, прохождение пяти решений, просмотр сохранённых документов, возврат на главную, виджет соцсетей, подписи сервисов и скачивание PNG-открытки.
